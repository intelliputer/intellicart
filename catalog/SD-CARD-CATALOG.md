# Intellicart SD-card catalogue

This catalogue records the 178-game `INTELLICART` microSD-card image prepared for the current firmware revision.

## Development status

- Every entry currently falls back to the root `0.cfg`; no game-specific CFG files are on the card.
- Compatibility is **unverified on physical Intellivision hardware** until the 74x245 transceivers are fitted and live testing is complete.
- Use the *Class* column to choose a deliberate test mix: standard retail titles first, then diagnostics, prototypes, demos, and system ROMs.
- The *SD filename* is the exact filename currently on the card. The firmware derives its OLED title/publisher display from this convention.
- Optional local cover thumbnails use `catalog/covers/NNN.png` (or JPG, JPEG, or WebP), where `NNN` is the catalogue number.

## Updating this catalogue

Regenerate after changing the card image. The source ROM directory and card filenames must retain the same alphabetical/numbered ordering used when the card was prepared.

```bash
python3 scripts/generate_sd_catalog.py \
  --card-dir /media/$USER/INTELLICART \
  --rom-dir ../rom-asm-intellivision/roms \
  --covers-dir catalog/covers \
  --output catalog/SD-CARD-CATALOG.md
```
