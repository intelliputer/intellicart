# Checkers ROM analysis workspace

This directory contains the CP1610 disassembly of the original Checkers ROM used for the human--agent gameplay prototype.

## Input

- ROM: [`../../rom/Checkers (1979) (Mattel).int`](../../rom/Checkers%20(1979)%20(Mattel).int)
- SHA-256: `07d5180de07d49260b45aa2795eef2479743af842496646bbef6bdd81f9a8ae9`
- Size: 8,192 bytes (4,096 big-endian 16-bit words)
- Cartridge mapping: `$5000`--`$5FFF`
- CPU: General Instrument CP1610

## Contents

- `checkers.asm` is the generated CP1610 assembly listing. The cartridge header at `$5000`--`$504F` is explicitly emitted as `DECLE` data; executable code begins at `$5050`.
- `checkers.sym` supplies the mapping and data boundary to the disassembler.
- `build-disassembly.sh` rebuilds the listing from the ROM using the adjacent `../sdk1600` repository.
- `extract-words.sh` produces a lossless, address-labelled word listing for manual annotation and verification.

The listing is mechanically generated and preserves the ROM words in comments. Labels are auto-generated by the disassembler, so semantic names for routines, board state, and human--agent hooks remain a separate annotation pass. The ROM itself remains unchanged.
